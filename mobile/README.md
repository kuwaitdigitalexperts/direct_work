# دايركت جوب الكويت | Direct Jobs Kuwait 🇰🇼

تطبيق التوظيف والخدمات المباشر الأول المخصص حصرياً لسوق العمل في **دولة الكويت**. تم بناء التطبيق باستخدام **Flutter (FVM)** و **Riverpod** مع الحفاظ على أعلى معايير الأداء والسرعة، واستخراج وتطابق الأصول والواجهات 1:1 من تطبيق Direct Jobs الأصلي.

---

## 📱 المميزات والخصائص الرئيسية (Kuwait Exclusive)

1. **التركيز الحصري على دولة الكويت**:
   - تقسيم جغرافي يشمل **المحافظات الست** (العاصمة، حولي، الفروانية، الأحمدي، الجهراء، مبارك الكبير).
   - التعامل بالعملة الرسمية: **الدينار الكويتي (KWD / د.ك)**.
   - التحقق من أرقام الهواتف والواتساب الكويتي (+965).
   - خيارات الدوام المتوافقة مع طبيعة السوق: **دوام كامل** و **دوام جزئي داخل الكويت** و **عمل حر**.
   - تصنيفات مرشحين مخصصة: **مواطنو دول مجلس التعاون (الكوادر السعودية)**، **غير محددي الجنسية (البدون)**، **مقيمون داخل الكويت**، و **باحثون من الخارج**.

2. **الأقسام والتبويبات الرئيسية (Tabs)**:
   - **الوظائف (Jobs)**: تصفح الوظائف، البحث المتقدم، الفلترة حسب القطاع والمحافظة، التقديم المباشر، التواصل عبر واتساب ومكالمات مباشرة.
   - **الخدمات (Services)**: سوق متكامل لخدمات الصيانة، التكييف، نقل العفش، بنشر متنقل، تنظيف ومكافحة حشرات.
   - **إعلانات تجارية (Commercial Ads)**: دليل وعروض الشركات والمراكز الطبية والسيارات في الكويت.
   - **المحادثات (Chats)**: نظام محادثات فوري 1-on-1 بين الباحثين عن عمل والشركات/أصحاب الخدمات.
   - **حسابي (Profile)**: إدارة السيرة الذاتية، الإعلانات المنشورة، تغيير اللغة (عربي/إنجليزي)، وباقات الترقية.

3. **إعلانات وبوابة الدفع**:
   - باقات إعلانية تبدأ من **1.5 د.ك** (إعلان قياسي)، **3.5 د.ك** (إعلان مثبت)، و **12.0 د.ك** (إعلان تجاري VIP).
   - تكامل جاهز مع بوابة الدفع الكويتية **MyFatoorah** لبطاقات **KNET** والبطاقات الائتمانية.

4. **الهوية البصرية والأصول الأصلية**:
   - ألوان التطبيق الأصلية: البرتقالي الأساسي `#FB8C00` والبرتقالي الداكن `#E47F07`.
   - الخط العربي واللاتيني المعتمد: **Cairo** و **Almarai**.
   - صور الشاشات الترحيبية الأصلية (Onboarding Slides 1-4).

## 🛠 البنية التقنية (Tech Stack)

- **Framework**: Flutter 3.47.4 (Dart 3.13.3) عبر **FVM**.
- **State Management**: **Flutter Riverpod** (v2.6.1).
- **Networking**: **Dio** مع Interceptors للتوكن والاتصال بخلفية Laravel.
- **Routing**: **GoRouter** (v14.8).
- **Backend Ready**: متوافق 100% مع **Laravel API (Sanctum / JWT)**.

## 🚀 تشغيل التطبيق محلياً عبر FVM

```bash
# 1. الدخول إلى مجلد المشروع
cd direct_job_kuwait

# 2. تحديث الحزم والاعتماديات
fvm flutter pub get

# 3. فحص الكود والتأكد من سلامته
fvm flutter analyze

# 4. تشغيل الاختبارات
fvm flutter test

# 5. تشغيل التطبيق على المحاكي أو الجهاز
fvm flutter run
```

## 🔌 مسارات الـ API للباك إند (Laravel API Endpoints)

تم تجهيز جميع استدعاءات الـ API لتتصل مباشرة بخلفية Laravel عبر المسار الافتراضي `http://10.0.2.2:8000/api/v1` أو الدومين المباشر:

- **المصادقة**: `POST /auth/login`, `POST /auth/register`, `POST /auth/register-company`, `POST /auth/verify-otp`.
- **الوظائف**: `GET /jobs`, `GET /jobs/{id}`, `POST /jobs/{id}/apply`.
- **الخدمات**: `GET /services`, `POST /services`.
- **الإعلانات التجارية**: `GET /commercial-ads`, `POST /commercial-ads`.
- **المحادثات**: `GET /chats`, `GET /chats/{id}/messages`, `POST /chats/{id}/send`.
- **الدفع (MyFatoorah)**: `POST /payments/myfatoorah/initiate`, `POST /payments/myfatoorah/verify`.
